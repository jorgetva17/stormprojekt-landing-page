# ⚡ Matheus Storm & Stormprojekt - Landing Page Oficial

Landing Page de alta conversão, interatividade e impacto visual para divulgação e venda de shows do artista e multi-instrumentista **Matheus Azevedo (Matheus Storm)** e sua banda **Stormprojekt** (@stormprojekt).

---

## 🎸 Destaques da Aplicação

- **Identidade Visual Eletrizante**: Design moderno com paleta Storm (Preto obsidiana, Ciano elétrico, Âmbar dourado e Púrpura de palco), com efeitos de glassmorphism e iluminação cênica.
- **Background Animado em Canvas**: Partículas reativas e ondas sonoras contínuas que simulam a energia de um palco ao vivo.
- **Console Sonoro Interativo ("O Som da Tempestade")**: Player dinâmico com sintetizador de áudio Web Audio API para demonstrar a sonoridade dos estilos (Rock, Jazz, Blues e Funk Groove).
- **Explorador de Repertório (+150 Clássicos)**: Catálogo com filtro por gênero (Rock Internacional, Rock Nacional, Jazz & Bossa, Blues & Soul, Pop & Grooves), busca em tempo real e montagem de setlist personalizado copiável para o WhatsApp.
- **Agenda de Shows & Ações**: Linha do tempo com datas públicas e calendário de disponibilidade para eventos privados.
- **Mídia & Reels Instagram (@stormprojekt)**: Vitrine interativa de vídeos, reels, solos de guitarra e fotos de bastidores com link direto para o Instagram oficial.
- **Simulador Interativo de Orçamento & Agendamento**:
  - Seleção de formato (Trio Acústico, Banda Standard, Big Experience com Metais)
  - Tipo de evento (Casamento, Corporativo, Aniversário, Festival)
  - Cálculo instantâneo e envio direto com mensagem pré-formatada para o WhatsApp da produção.
- **Mural da Comunidade & Perguntas dos Internautas**:
  - FAQ Oficial com respostas para as principais dúvidas de noivos e contratantes.
  - Mural interativo onde fãs e internautas enviam perguntas e recados com respostas de Matheus Storm e animação de confetes.
- **Botão Flutuante de WhatsApp**: Acesso rápido à produção da banda em qualquer ponto da navegação.

## 🚀 Como Hospedar na Vercel (Passo a Passo)

A landing page foi desenvolvida com **Vite + React + Tailwind CSS**, otimizada para carregamento ultra-rápido e 100% pronta para a **Vercel**.

### Opção 1: Via Vercel CLI (Direto do Terminal)

1. Instale a Vercel CLI (se ainda não tiver):
   ```bash
   npm install -g vercel
   ```
2. Na pasta do projeto (`d:\Projeto landpage Stormprojekt`), execute:
   ```bash
   vercel
   ```
3. Siga as instruções no terminal (pressione Enter para aceitar as configurações padrão). O arquivo `vercel.json` já configurou o framework Vite e o diretório `dist` automaticamente!

---

### Opção 2: Via GitHub + Vercel Dashboard (Recomendado para Atualizações Automáticas)

1. Crie um repositório no seu GitHub (ex: `stormprojekt-landing-page`).
2. Conecte e envie os arquivos locais:
   ```bash
   git init
   git add .
   git commit -m "feat: landing page oficial Matheus Storm & Stormprojekt"
   git branch -M main
   git remote add origin https://github.com/SEU-USUARIO/stormprojekt-landing-page.git
   git push -u origin main
   ```
3. Acesse [vercel.com](https://vercel.com) e faça login.
4. Clique em **"Add New..."** > **"Project"**.
5. Selecione o repositório importado do GitHub.
6. A Vercel detectará automaticamente as configurações:
   - **Framework Preset:** Vite
   - **Build Command:** `npm run build`
   - **Output Directory:** `dist`
7. Clique em **"Deploy"**. Em cerca de 30 segundos sua landing page estará no ar com link seguro `https://seu-projeto.vercel.app` e certificado SSL gratuito!
